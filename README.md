# SISU-IOL-Skill

面向 SISU IOL 同学的课程论文评价与写作辅助 Skill。它把真实论文、对应成绩、作业要求和教师批阅蒸馏为可供 agent 使用的规则，帮助同学判断：这份作业最值得改哪里、为什么、怎样改。

先匹配课程、学年与作业，再结合对应教师代号的偏好；没有这门课或该批次的数据时，使用全课程汇总的 **general 分析**，明确说明资料缺口，继续帮助选题、搭提纲、评价草稿与提交前修改。

重点是已评分论文显示的写作表现，以及具体教师批阅。通用评分表仅作辅助；题目小分和明确任务要求保留。项目不承诺成绩，也不把历史高分文章当成事实无误的标准答案。

## 开始使用

完整复制 `skills/course-grade-guide` 文件夹到支持 `SKILL.md` 的 agent 的技能目录，保留其中的 `courses`、`teachers`、`general` 和 `scripts`。也可以把该目录交给 agent，要求先读取 `SKILL.md`；日常阅读与评价不需要运行 Python。

示例请求：

> 使用 course-grade-guide，评价我在 2025-2026 学年第二学期“心理语言学研究方法”的第二次课堂实验报告。我还有两小时修改，请优先指出影响评价的三个具体问题，定位段落并给出改法。以下是本次要求和草稿……

从 [课程索引](skills/course-grade-guide/courses/index.md) 查看对应关系。教师使用稳定代号，同一代号跨年保持不变；同名课程换教师时创建新开课批次。未知年份不自动选择最近年份。

未收录课程也可以直接使用：

> 使用 course-grade-guide。目录里没有我的课程，请先明确说明缺少本课数据，再用 general 分析检查这篇论文的论证和结构，定位最值得修改的段落。以下是本次要求和草稿……

输出应包括：评价依据与缺口、主要优点、具体问题位置、可执行修改、优先级与成本、修改后的复查标准。不会只有泛泛的“逻辑需加强”，也不要求为了贴合旧案例而更换研究主题或堆叠技术。

## 项目结构

```text
skills/course-grade-guide/
├─ SKILL.md       使用入口与评价流程
├─ courses/       课程、开课批次与具体作业规则
├─ teachers/      稳定代号与有适用边界的候选偏好
├─ general/       全课程汇总的方法，供无课程数据时使用
└─ scripts/       可选的课程匹配工具
maintainer/       完整案例贡献模板、蒸馏流程及检查工具
```

日常只需安装 `skills/course-grade-guide`。维护者工具不随日常评价加载。仓库保留的是抽象规则，原始论文、个人精确成绩、原文批阅与教师身份映射独立保存在私人资料中，即使本仓库设为私密也不上传这些原件。

## 当前覆盖与局限

- 已整理 12 门课程、7 个教师代号、60 条课程诊断规则与 8 项 general 分析方法；教师档案引用课程规则，避免维护两套标准。
- 已有材料以单一贡献者为主。多篇同作者论文不等于多个独立学生的验证。
- 部分课程有直接批阅，部分只有任务说明和已评分论文；档案分别标注证据边界。
- 语用学已补入单篇评分依据；认知科学导论目前只有课程总评，不能拆成单篇成绩。心理语言学要求已确认对应所列批次，忽略文件中未更新的旧年份。
- general 汇总全部已整理课程，按作业类型选择适用方法；它提供院内案例启发，不代表未收录课程的独立数据或教师偏好。
- 第一版只完成材料整理、规则核验与功能检查，未证明实际提分幅度。尚未启用历史分数预测。
- 代号减少直接姓名暴露，不保证无法通过课程与年份推知教师身份。项目不是教师发布或背书的官方评价标准。

## 贡献完整案例

贡献须包含实际获评分的论文原件、对应得分及其范围、教师身份、课程、学年与作业类型；有要求、批阅和分项得分时一并提供。只有几句 comment 不进入案例库。

先联系维护者确定私人交付渠道，再使用 [贡献模板](maintainer/contribution-template.json) 提交文件夹或压缩包。**不要把原件、成绩截图、教师原文批阅或身份映射上传到公开 Issue、讨论或 Pull Request。** 尚无在线上传服务。

贡献者允许私人分析和公开抽象规则的范围分别记录。公开仓库只包含经过脱敏的规则、流程和合成测试材料。实际公开提交前，由维护者核查授权、证据与隐私；自动检查通过不等于已经完成这项人工核查。

维护流程见 [蒸馏与更新](maintainer/workflow.md)。公开修改可以提交规则和文档差异，来源核验记录留在私人资料中。

新增案例会对现有规则提出支持、修订、缩小适用范围或新增规则的建议；同一课程换年份或教师时，增加开课批次，不覆盖原来的对应关系。general 中的每项方法也保留课程规则来源，随案例增长修订。

## 本地工具

Python 3.10 或以上。课程匹配、校验和测试仅使用标准库；只有 PDF 提取需要 `pypdf`，依赖见 [requirements.txt](maintainer/requirements.txt)。脚本不联网、不调用模型、不自动发布。

在本仓库根目录运行：

```powershell
python -X utf8 skills/course-grade-guide/scripts/resolve_course.py --course 心理语言学研究方法 --year 2025-2026 --assignment report-2
python -X utf8 maintainer/validate.py
python -X utf8 -m unittest discover -s maintainer/tests -v
```

私人提取和发布检查的路径参数、使用方式及局限见维护流程。只把这个仓库目录上传 GitHub；不要在包含私人原件的上级目录建仓库。当前版本不附带原始论文、成绩表或学生范文。
